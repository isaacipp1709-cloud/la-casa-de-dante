# Roadmap y Fases de Desarrollo

Este Roadmap proyecta el crecimiento progresivo de **La Casa de Dante**.

- [x] **Session 01: Fundación** - Auditoría, inicialización de Next.js, andamiaje seguro, dependencias bases y generación de documentación universal.
- [ ] **Session 02: Frontera de Adaptadores** - Creación del `dante-bridge`, configuración Zod y validaciones.
- [ ] **Session 03: Arquitectura UI/UX** - Creación de Layouts, Navbar, y bases del Dashboard en Tailwind.
- [ ] **Session 04: Motor de Chat** - Implementación de la caja de chat con streaming de Groq Cloud en el borde (Edge API Routes).
- [ ] **Session 05: Panel de Neuronas (Telemetría)** - Visualización del estado del `Dante-AI-Core` usando Recharts.
- [ ] **Session 06: Seguridad & Base de Datos** - Integración de Supabase, tablas base y Row Level Security.
- [ ] **Session 07: Ingestión Documental** - Funcionalidad de subida de archivos y validación MIME.
- [ ] **Session 08: Vinculación con Dante-AI-Core** - Inyección completa de la API al cerebro y tests integrados.
- [ ] **Session 09: Ajustes Visuales & Accesibilidad** - Refinamiento de la interfaz bajo revisión de subagentes de accesibilidad.
- [ ] **Session 10: Deploy Final** - Despliegue en Vercel, pruebas de observabilidad total y certificación de Costo $0.
